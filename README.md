# Samuel Naanyoung Ezekiel — Personal Portfolio

A futuristic, responsive personal portfolio built with React, Vite, Tailwind CSS, Framer Motion and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

The repository is configured for GitHub Pages at:

https://samzeeezzy.github.io/portfolio/

The GitHub Actions workflow builds the Vite app and deploys the `dist` directory whenever changes are pushed to `main`.

In GitHub, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**.

## Personalisation

Update project links, contact details, biography and skills in `src/App.jsx`. Global styles and responsive behaviour are in `src/index.css`.
